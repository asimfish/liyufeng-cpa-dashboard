# Codex CPA 小时状态看板

GitHub Pages 地址：<https://asimfish.github.io/liyufeng-cpa-dashboard/>

看板按北京时间显示账号本小时状态、小时剩余时间、下一次探测倒计时、代理池失败次数、当前基线来源、异常三次确认进度和最近会话归因。中心主账号标记为 7973。

令牌会缓存到浏览器的 `localStorage`，页面上的“清除缓存”可删除。首次在 Mac 上复制本地只读看板令牌：

```bash
pbcopy < ~/.local/share/liyufeng-codex-vpn-local/dashboard.token
```

这个令牌不是 CPA 管理密钥，也不是模型客户端 API key。状态页不会显示 OAuth token、请求体或完整响应状态头。没有会话归因时，页面会明确显示“暂无会话归因”，不会把账号级记录伪装成某个会话的结果。

## 回复速度与中心负载

主面板新增被动性能采集：最近 15 分钟的响应头等待、首段响应等待、完整传输耗时 P50/P95，以及按账号划分的在途请求和失败计数。首段可能是协议事件，不能当作首个文字 token；HTTP 成功也不证明模型能力。

中心负载包括 CPU、内存、磁盘、各账号 CPA/网关的 cgroup 内存及上限。每 15 秒刷新，60 秒未更新显示过期；缺失账号与无样本指标显示未知。告警只提示，不会自动重启、限流或切换。测速不会额外发送模型请求。

## 账号额度暂停

收到明确的额度耗尽响应后，账号暂停定时扫描、异常确认和管理页手动探测。只有可靠的上游重置时间到达后，才在额外等待 30 秒后安排一次恢复检查；没有重置时间则保持暂停。页面按北京时间显示重置日期，暂停期间不显示即将扫描的倒计时。

认证失败、限流和额度耗尽属于账号状态，不计为节点故障或模型降级。历史节点错误如果包含账号错误，会显示“账号错误，节点未判定”，保留原始历史计数供审计。其他账号继续独立运行。
